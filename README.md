# AURELIA — Residence 01

### Luxury Real Estate / Architectural Concept

AURELIA Residence 01 — концептуальный luxury real-estate проект,
созданный как цифровая презентация современного жилого комплекса.

Проект сочетает архитектуру, editorial-дизайн и интерактивную
презентацию здания в одном web-интерфейсе.

> CONCEPT PROJECT / FICTIONAL DEVELOPMENT

---

## ✦ CONCEPT

AURELIA — это вымышленный премиальный жилой комплекс,
расположенный в Бишкеке, Кыргызстан.

Главная идея проекта — показать недвижимость не как обычный
каталог квартир, а как полноценный архитектурный experience.

Пользователь не просто смотрит страницу.

Он исследует проект.

Можно:

- приближать архитектуру;
- отдалять модель;
- перемещать здание;
- изучать архитектурные элементы;
- просматривать типы резиденций;
- изучать концепцию проекта;
- знакомиться с локацией;
- перейти к запросу презентации.

# ✦ DESIGN PHILOSOPHY

AURELIA построена вокруг идеи:

> «Жизнь выше горизонта.»

Визуальный язык проекта основан на сочетании:

- современной архитектуры;
- тёмной цветовой палитры;
- натуральных оттенков;
- editorial typography;
- минималистичной графики;
- архитектурных сеток;
- тонких линий;
- золотистых акцентов;
- крупных фотографий;
- интерактивных элементов.

Цель дизайна — создать ощущение сайта настоящего
международного девелоперского бренда.
